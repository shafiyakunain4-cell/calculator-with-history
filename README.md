# 🧮 Calculator with History - Python

A Python console calculator that saves all calculations permanently using File Handling.

## ✨ Features
- ➕ Addition, Subtraction, Multiplication, Division
- 📜 View calculation history anytime
- 🗑️ Clear history option
- 💾 Permanent storage in `history.txt` (File Handling)
- ⚠️ Handles divide-by-zero and invalid inputs

## 🛠️ Tech Used
- Python 3
- File Handling (open, read, write, append)

## ▶️ How to Run
1. Download `calculator.py`
2. Run: `python calculator.py`
3. Choose option from menu

## 📂 Project Structure
- calculator.py - Main calculator code
- history.txt - Auto-created file that stores history
- README.md - Project documentation
